## Hi there 👋

### 一、开源类

#### 1.chat

简单实现即时聊天系统（包含Server、PC、Android、iOS、Web多端通讯），更多详见[link](https://github.com/zhouyige66/Chat)。

#### 2.ScreenShot

Android截屏工具库（截取当前应用屏幕图像的工具类），更多详见[link](https://github.com/zhouyige66/ScreenShot)。

#### 3.RequestPermission

基于Aspectj实现的动态权限检查、权限申请库，更多详见[link](https://github.com/zhouyige66/RequestPermission)。

#### 4.RequestPermissionExt

基于APT、JavaPoet、Javassist实现动态权限申请的工具库，更多详见[link](https://github.com/zhouyige66/RequestPermissionExt)。
